included SIL Open Font License 1.1 (`OFL.txt`).

Source snapshot: [google/fonts at b5829bab95a0d159d14bc4abc8a88ad578d324f3](https://github.com/google/fonts/tree/b5829bab95a0d159d14bc4abc8a88ad578d324f3/ofl/ibmplexsans).

static weights used by `scripts/generate-og.mjs`. There is no build-time download.
